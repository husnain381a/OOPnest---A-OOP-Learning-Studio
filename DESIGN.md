# OOPnest desig

An approachable study workspace for university students, in Operate mode for dashboard/editor and Read mode for lessons. Warm cream surfaces, forest green primary actions and restrained peach, sage, blue and mauve topic illustrations. The visual emphasis is the relationship between a familiar object and its code representation.

Use a persistent desktop sidebar and collapsible mobile navigation. One familiar sans family, consistent buttons, readable prose, and monospace for code. Provide a dedicated login and signup screen before the learning workspace. Show keyboard focus and respect reduced-motion preferences. Label expected output and live execution results clearly.

Primary values and surface colors are in app/globals.css. Keep all sections within the main content edges. At narrow sizes, stack lesson/editor panels, collapse navigation and keep code horizontally scrollable within its editor. All progress figures derive from completed lessons rather than invented activity.
