# OOPnest product

Students learning object-oriented programming in C++ need familiar analogies before formal terminology. The primary flow is story → mapping → complete code → quick check → playground challenge. Students log in or create an account with email and password to open the dashboard and sync notes and completion. Educators need a restricted student directory and progress view. Hindi and Urdu learning resources and Hindi/Roman Urdu explanations make concepts more approachable.

Use Next.js, Tailwind and Supabase for the workspace. Live C++ execution uses OnlineCompiler and requires an API key. Keep the initial hosted review private and show real account data and execution results when the services are configured.
